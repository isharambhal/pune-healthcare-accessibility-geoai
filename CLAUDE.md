# Project rules for Claude

Project: GeoAI healthcare accessibility for Pune Municipal Corporation (41 wards).
I am a master's student with developing Python skills. Teach as you build.

## Working rules
- Work in small stages. Explain each file and how I can test it.
- Never invent data, results, formulas, or statistics. Mark every claim as:
  recovered, assumed, proposed, or needs verification.
- Ask before major methodology changes or new features.
- Do not substitute datasets silently. State source, date, CRS, licence.
- Do not call a feature complete until it is implemented and tested.
- Keep the live app light: heavy analysis runs offline, the app loads results.
- Never commit raw data, credentials, or personal documents.

## Stack
Python, GeoPandas, Streamlit. Optional later: OSMnx, PySAL/esda, scikit-learn, SHAP.
